PDF 進階工具

依輸入順序輸出，可重複頁面。PDF 修改將使既有數位簽章失效。

頁面管理

重整不降低圖片解析度，不保證檔案縮小。擷取／合併可能不保留書籤、附件、互動表單。

文字、圖片與浮水印

加註文字以圖片嵌入，可顯示中文但不可搜尋；不會刪除或改寫既有文字。座標以原始頁面左下角為原點。

簽名與表單

手寫圖像簽名，不是憑證式數位簽章。使用上方 X／Y／寬／高定位。

保護與真正遮蔽

產生 .pdsenc 專用備份，需要此工具及密碼還原；不是標準 PDF 開啟密碼。

使用 X／Y／寬／高，黑色區域會從重建的影像移除；全部頁面影像化，原文字層與互動內容不會保留。下載前必須檢視遮蔽位置。

轉換與比較

文字抽取不重建表格與版面；掃描檔請使用 OCR。比較僅比文字，不比視覺。

應用程式更新

GitHub Releases 需提供 studio-update.json 資產；自訂 HTTPS 來源需允許跨來源讀取。ZIP 以 SHA-256 比對，下載後解壓開啟新版。瀏覽器不能靜默覆寫本機應用程式。
