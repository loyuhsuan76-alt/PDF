# PDF Studio Pro 3.0

解壓縮完整資料夾後，用桌面版 Chrome 或 Edge 開啟 `index.html`。必須保留旁邊的 `vendor` 資料夾。日常 PDF 與 Office 基本功能不需伺服器；OCR 模型與版本檢查需要網路。

## 已實作

- PDF：本機選檔／拖放、閱讀、下載原檔與工作副本、頁面擷取與排序、刪頁、合併、每頁拆分 ZIP、旋轉、檔案結構重整。
- 加註：文字圖片、浮水印、PNG／JPG、手寫圖像簽名、ASCII 文字表單、核取方塊、填寫文字欄、扁平化表單。
- 保護：AES-GCM 256 位元專用備份（PBKDF2-SHA256，250000 次）；並非 PDF 標準開啟密碼。需要密碼才能還原。
- 遮蔽：指定頁面的指定矩形以黑色覆蓋，整份文件重新生成影像 PDF，不帶原文字層、附件或表單。完成後請人工確認遮蔽位置。
- 轉換：PDF 文字抽取到文件編輯區、逐頁 PNG ZIP、逐頁文字比較報告。
- Office 文件：段落／表格編輯、字型、字級、文字／背景色、粗體、斜體、底線、對齊、段前段後、行距、左縮排、表格列欄／寬度／框線、尋找取代、A4／Letter 與邊界。匯出真正 DOCX、HTML，或透過列印另存 PDF。
- 試算表：單工作表、儲存格編輯、四則運算、引用、SUM／AVERAGE／MIN／MAX／COUNT、統一字型色彩、欄寬、數字格式、CSV 匯入匯出、真正 XLSX 匯出。
- 簡報：16:9、標題／內文、投影片增刪、字型色彩與背景、真正 PPTX 匯出。
- Office 匯入：DOCX 的段落與一般表格、XLSX 第一張工作表的值與公式、PPTX 文字、TXT。匯入前會提示可能遺失的內容。
- OCR：圖片及 PDF 指定頁、繁中／簡中／英文／日文、信心值、取消功能、結果附加到文件。模型由 jsDelivr 下載，辨識在本機執行，不上傳文件。
- 自檢：格式規則檢查、匯出檔重新開啟驗證、公式錯誤、替代字元、控制字元、文字與背景同色、異常字級／行距、表格欄數、簡報文字量。
- 自動修整：修復不合法字級／色彩／行距、移除控制字元、補齊表格欄數，可復原。無法判斷的亂碼與語意不會擅自替換。
- 錯誤處理：捕捉例外、保留原檔、下載 JSON 診斷報告。並非自主改寫自身程式的除錯系統。
- 草稿／歷史：Office 本機自動草稿、專案 JSON 備份、Office 復原／重做；PDF 最多保留 8 次工作副本歷史。

## 重要界線

目前無法等同完整 Acrobat 或 Microsoft Office，也不能宣稱所有格式完全保真。

- 不支援直接改寫 PDF 原有段落／原字型；加註中文文字以圖片嵌入，不可搜尋。
- 文字抽取不重建原 PDF 版面與表格；OCR 不會直接產生保留原版面的可搜尋 PDF。
- 不支援標準 PDF 密碼設定／解密、憑證式數位簽章。已簽章 PDF 的編輯會使原簽章失效。
- 加密 PDF 請先用有權限的閱讀器解密；不能繞過密碼。
- 重整不是有損圖片壓縮，不保證檔案縮小。
- Office 匯入會遺失複雜版面、圖片、圖表、註解、混合文字格式、合併儲存格等；原檔不改動。XLSX 只編輯一張工作表；PPTX 只取文字且以 slide 檔案編號排列。
- Office 每個區塊採統一字型格式，不支援任意字元範圍的混合格式。試算表與簡報不是原生 Office 的完整功能集。
- Office 匯出未嵌入字型；目標電腦缺少字型時會替代。分頁、換行、色彩呈現、字形正確性仍需用 Word／Excel／PowerPoint 或 PDF 閱讀器檢查。
- 程式內自檢只代表已列出的規則及檔案結構通過，不是原稿相似度、OCR 正確率或完整排版保真認證。

## 更新

更新中心支援 HTTPS manifest 或公開 GitHub 儲存庫網址。預設每 24 小時檢查一次（網頁必須開著），並向 npm registry 查詢已打包元件的版本。

應用程式更新來源必須先實際建立與發布；未設定來源時不會聲稱已完成應用程式更新。新版 ZIP 下載前會驗證 SHA-256；自動下載可自行勾選，瀏覽器可能要求允許下載。GitHub 的跨來源讀取如果遭限制，會顯示失敗並保留目前版本。

瀏覽器不能靜默覆寫本機 HTML。下載後仍需解壓縮並開啟新版；專案可由 JSON 重新匯入。元件更新需整合、測試、重新發布版本，不會直接執行任意遠端新版程式。沒有伺服器，也沒有帳號 Token 存在 HTML。

## 隱私

文件內容留在本機。更新請求只傳送所需的版本查詢；OCR 只下載程式與模型。草稿存於瀏覽器 localStorage；共用電腦請自行管理草稿與下載檔。診斷报告可能含使用者欄位名稱或檔名，分享前請檢視。

## 驗證狀態

Node.js 實測 DOCX／XLSX／PPTX 產生及重新解壓，PDF 頁面與表單操作、公式及規則檢查、程式語法、HTML ID 與所有本機資源路徑。
另以 python-docx、openpyxl、python-pptx、pypdf 獨立核對範例檔的文字、格式、公式快取值與頁面順序。

目前環境未完成真實桌面瀏覽器的端對端畫面、原生拖放、OCR 下載、字型渲染與更新下載驗證；不能將上述程式測試當作完整視覺驗收。

第三方套件與字型授權見 `THIRD-PARTY-LICENSES.txt`。
